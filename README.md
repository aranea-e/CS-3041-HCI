# Spellbook Organizer for LARP

## Overview
The Spellbook Organizer is a web application designed for Live-Action Role-Playing Games (LARP). It allows players to easily organize and select spells during gameplay. The application features a user-friendly interface with a grid layout for quick access to spells.

## Project Structure
```
spellbook-larp
├── src
│   ├── pages
│   │   ├── spelllist.html   # Main HTML document for the application
│   │   └── selection.html   # Spell selection page
│   ├── css
│   │   └── styles.css      # CSS styles for the application
│   └── js
│       └── main.js         # JavaScript code for handling interactions
├── package.json            # Configuration file for npm
├── .gitignore              # Files and directories to ignore in version control
└── README.md               # Documentation for the project
```

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, etc.)
- Basic understanding of HTML, CSS, and JavaScript

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd spellbook-larp
   ```

### Running the Application
- Open `src/pages/spelllist.html` in your web browser to view the application.

### Usage
- Click on any of the "Select Spell" buttons to navigate to the selection page. The selection page is currently blank and can be populated with spell details in the future.
